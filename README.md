# EasyBook — Intelligent Fleet Automation & Smart Car Rental Platform

EasyBook is an AI-powered, IoT-enabled car rental and fleet management platform designed for modern rental operators. It automates fleet tracking, predictive maintenance, dynamic pricing, and seamless digital booking workflows.

## Features

- **Fleet Intelligence**: Real-time telemetry, vehicle health monitoring, battery/fuel tracking, and automated service reminders.
- **Smart Bookings**: Digital reservations, keyless entry dispatch, and automated check-in/check-out.
- **Live Fleet Map**: Track vehicle locations, geofencing, and driver status in real-time.
- **Revenue & Analytics**: Utilization rates, revenue forecasting, dynamic pricing optimization, and automated reporting.
- **Responsive Web Dashboard**: Clean modern UI with dark mode, interactive charts, and live fleet management controls.

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Shyam365-ai/EasyBook.git
   cd EasyBook
   ```

2. Open locally with any static web server (e.g., Python):
   ```bash
   python -m http.server 8080
   ```

3. Open in your browser:
   - Fleet App Dashboard: `http://localhost:8080/app.html`
   - Marketing Landing Page: `http://localhost:8080/index.html`
